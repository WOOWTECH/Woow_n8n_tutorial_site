Install a node or give AI a skill to extend n8n

n8n includes 400+ official nodes. Its global community adds another 2,100+ community nodes and dozens of MCP servers that let AI agents write workflows directly. This handbook selects 10 that homes, small and midsize businesses, and internal teams will actually use, plus 6 popular collections, installation reference, compatibility and safety guidance, and the SKILL.md specification.

How this list was compiled:Star counts, downloads, and maintenance status are public npm/GitHub data observed on 2026-08-20 and will change over time. Check the source repository again before installing.

The two ways to extend n8n

n8n has two extension models, both covered here:

  • Community Node: adds a node to the canvas for use in a workflow, such as Puppeteer for web capture or ElevenLabs for TTS. Every npm package named n8n-nodes-* belongs to this category. By 2026-08 there were more than 500 packages and 5,800+ skill-level units.
  • AI Agent Skill / MCP Server: gives your AI (Claude, Cursor, or Windsurf) another capability. Connect n8n-mcp and ask it to build a workflow; AI calls the n8n API directly. This model teaches AI how to communicate with n8n and is separate from the workflow itself.

Both expand what you can automate. A community node gives n8n another capability; an MCP server removes a task from the person operating n8n.

How to install (the 3-minute version)

Install a community node

  1. Open n8n Settings → Community Nodes

    Admin access is required. Self-installation is disabled by default in the managed service (n8n.woowtech.io); contact WoowTech. It is available on a local add-on or other self-hosted n8n instance.

  2. Select Install a Community Node and paste the npm package name

    For example: n8n-nodes-mcp, n8n-nodes-puppeteer, @elevenlabs/n8n-nodes-elevenlabs. Accept the risks of third-party packages, then select Install.

  3. Reload n8n (or wait for it to restart automatically)

    After installation, search for the node in the editor’s nodes panel. If it appears, installation succeeded. If not, check Executions → Errors; package incompatibility is a common cause.

  4. Add the node and run it once

    The official template or repository README usually includes a minimal working example. Connect credentials and test it.

Install an MCP server (for your AI)

In Claude Code, Cursor, or Windsurf, add this to settings.json or the MCP config:

{
  "mcpServers": {
    "n8n-mcp": {
      "command": "npx",
      "args": ["-y", "n8n-mcp"],
      "env": {
        "N8N_URL": "https://n8n.woowtech.io",
        "N8N_API_KEY": "<your API key, created under n8n Settings → API>"
      }
    }
  }
}

Save and restart the AI client. Tools such as create_workflow, list_workflows will appear.Prompt Librarycontains 44 copy-ready prompts.

Tip:An MCP server usually does not change n8n itself; it lets AI call the API. You can use it with self-hosted, Cloud, or any n8n instance, including n8n.woowtech.io after your account is created.

n8n MCP servers · Give your AI a workflow builder

An MCP server teaches your AI how to communicate with n8n. After connecting it, ask Claude or Cursor to build a workflow and AI uses the n8n REST API to create, activate, or debug it. These are the most active options:

czlonkowski/n8n-mcp

22.7k ★ · MIT · Very active (1,193 commits)

The n8n MCP server with the most stars and broadest feature set: 7 Core Tools (node search, validation, template discovery, docs) and 16 Management Tools (workflow CRUD, execution, folder, credential, audit, health). It covers 2,541 n8n nodes (832 core + 1,709 community)99% property.

npx n8n-mcp

Installation also supports Docker (ghcr.io/czlonkowski/n8n-mcp), local npm installation, and one-click Railway deployment. A prominent option in the source snapshot; verify current maintenance and releases before adoption.

makafeli/n8n-workflow-builder

540 ★ · MIT · Active (56 commits)

A lighter option: 15 tools across 5 categories (Core Workflow, Lifecycle, Advanced, Execution, Organization). Its strengths are create_workflow_and_activate in one step and generate_audit for one-step security audits. It suits intermediate users who do not need node search.

npx @makafeli/n8n-workflow-builder

Written in TypeScript, with complete CI and responsive issue handling. A good starting point for individuals and small teams.

salacoste/mcp-n8n-workflow-builder

229 ★ · MIT · Multi-instance support

17 tools (8 workflow + 4 execution + 5 tag + 6 credential), featuring Multi-Instance Support: one MCP server manages dev, staging, and prod n8n instances with automatic AI routing. It suits midsize teams with several environments.

npm i -g @kernel.salacoste/n8n-workflow-builder

38+ pages of detailed documentation and careful credential isolation between environments make it suitable for multi-environment deployments.

ifmelate/n8n-workflow-builder-mcp

≈200 ★ · Supports VS Code, Cursor, and Claude Code

Emphasizes “agent mode”: AI iterates from a natural-language prompt, automatically creating → running → observing errors → modifying. This is closest to AI coding inside an IDE.

For engineers who already write code in Cursor or VS Code.

Compatibility notes

Whether a community node or MCP server runs in your environment usually depends on three things:

  • n8n version: a node often pins a range of n8n minor versions. WoowTech’s n8n.woowtech.io is recorded in this repository as running v2.32.7 Community Edition; the public settings endpoint does not expose a version, so confirm it in the instance. Before installation, check peerDependencies.
  • Node.js version: a node using newer syntax such as optional chaining or top-level await will fail when n8n runs on an older Node.js. The HAOS add-on defaults to Node 20 and is usually compatible.
  • Additional service dependencies: Puppeteer, for example, needs a Chromium binary not included in the n8n Docker image. Add a Dockerfile or use the standalone image for n8n-nodes-puppeteer .

MCP server compatibility is simple: if your AI client (Claude Code, Cursor, or Windsurf) supports MCP, it works. It has no direct dependency on the n8n version because it calls the n8n API.

Concept:Your first criterion should not be star count. Check whether the maintainer is active: commits in the past 3 months and responses to issues.

Safety rules

Warning:A community node is an npm package that can execute arbitrary code; an MCP server is a process that can call your n8n API. Understand the implications before installing either.
  • Read the README before installing: not every package clearly documents the credentials it needs or the requests it sends. Ask Claude to review it if necessary.
  • Pin versions in production: package.json Use n8n-nodes-xxx: 1.2.3 rather than ^1.2.3 to prevent an unnoticed upgrade from introducing an upstream regression.
  • Use a scoped API key for an MCP server: create a dedicated n8n API key for MCP and limit access to a specific workflow tag or read-only operations.Do not use an admin key.
  • Review contributors: a node with only 1 contributor may stop receiving updates if that person leaves. Packages maintained by an official or commercial organization are safer for production.
  • Run an audit after installation: MCP servers provide a generate_audit tool. Run it once to detect possible leaks from newly installed nodes.

SKILL.md spec at a glance (for AI agent skills)

If you want to write an AI Agent Skill for Claude or Cursor, Anthropic’s SKILL.md format is the current de facto industry standard. The smallest structure is:

n8n-workflow-review/
└── SKILL.md          ← the only required file

# SKILL.md contents
---
name: n8n-workflow-review
description: When a user provides n8n workflow JSON, check its structure—
  find dangling connections, missing credentials, and clear performance problems.
  Also trigger when the user asks “Does this workflow have a problem?” or “Review this.”
---

# n8n Workflow Review

(Instructions for the agent, written as if onboarding a colleague)
FieldRequiredDescription
nameYesLowercase alphanumeric characters and hyphens, 1–64 characters.
descriptionYesWhat it does + when to use it. AI uses this line to decide whether to load the skill, so include phrases a user would say.
license / compatibility / allowed-toolsNoOptional fields for license, compatibility notes, allowed tools, and more.

Keep SKILL.md concise. Put supporting files under references/, scripts/, assets/ and read them only when needed to avoid filling the AI context.

Tip:An n8n skill usually maps a workflow pattern to an MCP tool. For a lighter approach, put the example in the Prompt Libraryinstead of making it a skill.

FAQ

Why does an installed community node not appear in the nodes panel?
The two most common causes are (1) n8n was not reloaded or the add-on was not restarted, and (2) an incompatible version. Check Settings → Community Nodes for a red error message. If it still does not appear, search the node’s GitHub issues for the same symptom.
Do community nodes affect n8n performance?
Every node consumes memory because its class remains loaded. Installing 50+ nodes makes n8n start 5–10 seconds more slowly. Keep frequent-use nodes and uninstall experiments you no longer need. Review them during audits.
Must an MCP server run continuously? Does it use many resources?
An MCP server is a short-lived process that communicates over stdio. It runs when your AI client starts and stops when the client closes. CPU and memory use are nearly zero.
Can WoowTech’s n8n.woowtech.io users install community nodes themselves?
Not by default. In a multi-user managed environment, adding a node affects every customer. Open a ticket; WoowTech will review the community reputation and security, then install it centrally if approved. For complete control, use the self-hosted option (see the Sales Handbook).
Can I star an npm skill/node package and track it without installing it?
Yes. npm has favorites, GitHub has stars, and awesome-n8n has issue subscriptions. Save it and watch the trend, then install only when needed.
How do I publish a new community node or skill?
For a community node, publish to npm with keywords: ["n8n-community-node-package"] and n8n will index it automatically. For an AI Agent Skill, push it to GitHub and submit it to topics/claude-skill. When mature, open a PR to awesome-n8n or the relevant skill index.
