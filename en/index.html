n8n Resource Hub

Hand repetitive work over to automation. These four handbooks cover how to use n8n, how to offer it to customers, how to have AI build with it, and which nodes and MCP servers you can install. Three are downloadable as single HTML files for offline reading.

The four handbooks

Onboarding tutorial

For users · 22 chapters + 3 appendices

Start by opening Woow n8n, using someone else's template, and building your first workflow. Then continue through expressions, the Code node, AI Agent, and Webhook. Each chapter takes 10 minutes.

Read online Full-site zip

Sales Handbook

For customers and resellers · Single page

Hand work that people do—but should not have to do—to workflows. Compare Option A (self-hosted) and Option B (managed by WoowTech), six real scenarios, the Template Package, and SLA terms.

Read online Download HTML

API/MCP Prompt Library

For engineers and AI agents · 44 copy-ready prompts

Have Claude or Cursor build a workflow from one request. The 44 prompts cover eight categories: generation, triggers, data transformation, SaaS integrations, AI Agent, error handling, debugging, and operations. Each invokes an n8n MCP tool or REST API.

Read online Download HTML

Skill Handbook

For advanced users · Node catalog + MCP reference

Install a community node or give your AI an MCP server to extend n8n. Explore 10 notable nodes, including Puppeteer, ElevenLabs, MCP, and Evolution API; compare four major n8n MCP servers, including czlonkowski/n8n-mcp at 22.7k★; and review the safety rules.
