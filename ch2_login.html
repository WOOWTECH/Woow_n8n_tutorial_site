第 2 章

打開 Woow n8n：登入與 5 分鐘介面導覽

同事叫你「去 n8n 開一個 workflow」，可是網址在哪、帳號怎麼拿、進去要點哪？這一章帶你從瀏覽器打開 n8n.woowtech.io、輸入公司給的帳密、看到主頁、確認你進的是對的地方。看完你就有一個「可以開始動手」的工作區。

為什麼要先花五分鐘搞懂登入

公司裡通常是這樣：某天主管在 Slack 丟一句「這個重複工作你去用 n8n 排一下」，然後就沒有然後了。你 Google「n8n 登入」，結果跳出來的是 n8n.io（人家公司的雲端版），你註冊、登入、開始做，做到一半才發現：你進的根本不是公司那個實例，做出來的 workflow 同事看不到、公司的 credentials 也拿不到。

Woow 有自己架的 n8n，網址是 https://n8n.woowtech.io/。這一章就把三件事講清楚：

  • 網址——去哪裡按下 Enter
  • 帳號——怎麼跟 IT 拿、拿到的長什麼樣
  • 第一次登入——會看到什麼、看不到某東西時代表什麼

如果你還沒讀過第 1 章「什麼是 n8n」，建議先掃一下，這樣後面看到「Workflow / Execution / Credential」這幾個詞才不會愣住。

觀念：「登入 n8n」不是一件事。有 n8n.io 官方雲端版、有各種自架的實例、有公司內部版。Woow 這一份是自己架的，跟外面公開的雲端版是完全不同的兩個系統。帳號不通用、workflow 不會互相看到。

Woow n8n 是「自架實例（self-hosted instance）」

先把幾個名詞對齊。你之後跟 IT 講話會用到：

名詞意思對 Woow 來說是誰
n8n.io n8n 這家公司官網＋他們自己賣的雲端 SaaS 版 不是我們用的；只會去那邊看文件、抄 templates
Self-hosted 實例 把 n8n 這套軟體，架在自己公司伺服器上的版本 就是我們的 n8n.woowtech.io
Cloudflare Proxy 公司在中間放的一層 CDN／保護層 你連 n8n.woowtech.io 其實先經過 Cloudflare，再進到公司內部；所以你在家、在辦公室、在客戶那都連得到
HTTPS 網址開頭 https:// 的那個「加密連線」 Woow n8n 一定是 https，如果你看到 http:// 開頭代表你打錯了

簡單講：n8n.woowtech.io 就是「公司自己的 n8n」。跟你可能在家玩過的 n8n cloud、跟同事口中的「n8n 官方那個」，是不同的宇宙。你的 workflow 只會存在這一個實例裡，換個網址就找不到。

提示：把 https://n8n.woowtech.io/ 加到瀏覽器書籤，起名叫「公司 n8n」。之後就不用每次 Google 找路，也不會誤入 n8n.io 官方站。

帳號怎麼來的？

Woow n8n 的帳號不是你自己註冊，是由 IT／管理員在系統裡幫你開的。因為公司這個實例沒有設定 SMTP 寄信（實測 /rest/settings 回 smtpSetup: false），所以你不會收到官方 invite email；IT 會直接把一段邀請連結（Invite URL）或臨時密碼透過 Slack／面對面交給你。email 用什麼網域沒有硬性規定（n8n 沒有強制網域），Woow 慣例是 你的名字@woowtech.io，但如果 IT 用別的也是可以的。

如果你的帳號還沒被開通，直接看到 login 卡在原地按不進去，這章的「troubleshoot」段落會教你怎麼跟 IT 講、怎麼描述問題。

第一次登入的五個步驟

準備好瀏覽器（Chrome、Edge、Safari、Firefox 都可以），跟 IT 給你的暫時密碼放旁邊。

  1. 打開瀏覽器，網址列貼上 https://n8n.woowtech.io/

    按 Enter。網址一定要是 https，不是 http。如果你只打 n8n.woowtech.io，瀏覽器通常也會自動幫你補 https，這是正常的。

  2. 看到 n8n 登入畫面

    畫面是淡灰底（Woow 這一版沒開深色主題選項），中間一張白色卡片，卡片上方有 n8n 的粉紅／橘紅色連線節點 logo 加上小寫「n8n」字樣，下面兩個輸入框：Email 與 Password，一顆橘色 Sign in 按鈕，按鈕下方一行小字連結 Forgot my password（不是「Forgot password?」）。沒有「Sign in with SSO / Sign in with Google」的按鈕——因為 Woow 沒開 SSO。看到這個畫面就代表你連到對的地方了。

  3. 輸入 IT 給你的 email 與密碼

    密碼直接用 IT 給的字串（可能有大小寫、有特殊符號，複製貼上最保險，不要手打）。如果 IT 給你的是一段 Invite URL（例如 https://n8n.woowtech.io/signup?inviterId=…&inviteeId=…）而不是密碼，那你要走的是「接受邀請」流程——直接點那個網址，在跳出來的頁面自己設定密碼與姓名，設完會自動幫你登入。這種情況就跳到第 5 步。

    注意：如果你在自己電腦上，瀏覽器可能會問「要儲存這個密碼嗎？」——先按不要，因為下一步可能還要改密碼，存的是暫時密碼沒意義。改完之後再存新的。

  4. 按 Sign in（或接受邀請設密碼）

    如果 IT 給的是暫時密碼，登入後可以到 右上頭像 → Personal settings → Change password 自己換一組。n8n Community 版並不會強制第一次登入就改密碼，是你要主動去換。密碼長度最少 8 個字元（實測 passwordMinLength: 8），建議混英數與符號。

  5. 看到主頁：左邊側欄、中間工作區

    成功登入之後，你會被丟到主頁 /home/workflows。畫面分成三塊：左邊窄側欄（大約是 Overview／Workflows／Credentials／Executions／Insights／Templates／Help 這幾項，實際看到哪些依你的角色而定，見下一節）、中間主區塊（第一次通常是空的 Workflows 列表，或者一張「Get started」的引導卡片）、右下角一顆頭像（你的名字縮寫；n8n 的頭像在側欄底部，不是右上角）。

提示：Chrome／Edge 這種瀏覽器可以按 Ctrl+D（Mac 是 Cmd+D）把主頁加書籤。之後每次要用 n8n 直接點書籤就好。

看到什麼代表你真的登入成功了

登入這件事，「畫面切換」只是表面的成功。你要確認的是：真的進到自己的工作區、有你該有的權限。用這張核對表：

檢查項目OK 的樣子NG 的樣子
網址列 停在 https://n8n.woowtech.io/workflows 或類似路徑 還停在 /signin 或跳去別的網址
左邊側欄 看得到 Workflows、Executions、Credentials、Templates 這幾個項目 整片側欄沒出來，或只剩幾個灰色不能點
側欄左下角 有一顆圓形頭像（通常是你名字第一個字或 email 首字母），點下去可展開 Settings / Sign out 整個頭像區沒出來、或還顯示 Sign in 按鈕
頁面頂部 沒有紅色 error banner，也沒有「You do not have access」訊息 紅底白字的錯誤條，或整片畫面被錯誤蓋住
Workflows 列表 空的（第一次登入很正常），或已經有 IT 幫你放的示範 workflow 看到一整排看起來不認識的別人的 workflow ← 這其實不是 NG（可能是 workspace 共用），但你要小心不要亂改
觀念：第一次進來 Workflows 列表通常是空的，這是正常的。不代表你出錯，只是還沒人幫你放東西。往下讀就會學到怎麼開第一個。

「我看不到那個功能耶」——三種常見原因

登入完之後，最常見的困惑是：「同事說要點左邊的 Credentials，可是我根本沒有這一項欸？」 這通常不是 n8n 壞掉，而是你的權限、workspace 或帳號狀態的關係。對照表：

症狀可能的原因怎麼辦
Sign in 按了沒反應／畫面卡在登入頁 帳號被 disabled、email 沒開通、密碼打錯 找 IT 說「我的 n8n 帳號 xxx@woowtech.io 登不進去，Sign in 沒反應」，請他們檢查帳號狀態
進得去，但同事講的「Admin 面板 / Users 管理」你沒有 那是 Owner（實例第一個建立的人）或 Admin 角色才看得到，而 Admin 角色只在 n8n Cloud Pro / Enterprise 版才存在。Woow 這一版是 Community 版（實測 enterprise.saml/ldap/oidc 都是 false），只有 Owner 與 Member 兩種角色 正常現象；管理實例的事丟給 Owner 處理即可
進去看到一堆別人的 workflow 你被加進的是共享 workspace／專案，這些是同事的作品 不要亂點 Delete，也不要亂改欄位。要練習就自己按 New workflow 開新的，或在 Personal 空間裡練
Credentials 列表是空的，或看不到同事建的 credential Member 角色只看得到「別人分享給你的」＋「自己建的」credentials，看不到別人 personal 空間裡沒分享的 要用就請對方按 Share 分享給你，或請他把 credential 移到 Team project 底下
看到紅色 banner「You do not have access to this workspace / project」 你的帳號存在，但沒被加到那個 project 找 Owner，說「請把我加到 XX project」——講清楚專案名稱
看不到 Insights、Variables、Source Control 這種進階項目 這些是 Enterprise / Cloud Pro 才有的功能。Woow 是 Community 版，這些通通沒有 正常現象，不用擔心；本教程用得到的功能都在 Community 版可用範圍內
注意：n8n 的實例級角色（instance role）官方只有三種：Owner、Admin、Member（其中 Admin 是 Enterprise/Cloud Pro 才有）。網路上常看到的 Editor、Viewer 是專案級角色（project role），只在 Enterprise 有 team projects 時才會出現。Woow 這一版沒有 Editor／Viewer 這種角色，不要照搬 n8n 官方文件截圖的角色名稱來要求 IT。

手機、平板、公司電腦——多裝置能不能用

n8n 是純網頁 app，不用裝任何程式。理論上任何裝置只要有瀏覽器就打得開。但「打得開」跟「用得順」是兩回事：

裝置能做什麼不建議做什麼
公司／家裡電腦（≥ 13 吋螢幕） 做 workflow、拉節點、debug、看 execution、改欄位——全部功能 沒有
平板（iPad、Android tablet） 看 execution history、看 workflow 長怎樣、手動按 Execute 觸發 拉節點、大量編輯（觸控在 canvas 上很難精準）
手機 看今天的執行有沒有紅、按 Execute workflow 手動觸發、看通知 編輯 workflow（節點會擠成一團），或第一次登入設密碼（欄位太小容易打錯）
提示：手機看畫面破版時，Chrome 右上角選「桌面版網站（Desktop site）」通常會好一點，但也只是勉強能看。真的要做事情還是回電腦。

登入 session 也要注意：一個瀏覽器同時只能登一個 n8n 帳號。如果你要同時用兩個帳號（比如自己的 + 一個測試帳號），要嘛開無痕視窗（Incognito），要嘛裝一個不同的瀏覽器（Chrome 一個、Firefox 一個）。

兩個一定要記住的位置

登入後的介面之後會在第 3 章「工作區導覽」逐塊拆解。這裡只先講兩個你「隨時要用得到」的按鈕，記住它們，你就不會迷路：

  1. 左上角的 n8n logo ＝「回主頁」

    不管你在編輯某個 workflow、還是在看某個 execution 的錯誤細節，點左上角那顆 n8n logo 或側欄的 Workflows，就回到 workflow 列表主頁。這是你的「Home」按鈕。

  2. 側欄左下角頭像 ＝「Settings / Sign out」

    側欄最下面那顆圓形頭像（n8n 的頭像放左側欄底部，不是右上角，容易誤找）點下去，會展開一個小選單，裡面有 Settings（改密碼、改個人偏好等）和 Sign out（登出）。

    注意：用公司公用電腦的話，離開座位前一定要點 Sign out。n8n session 預設會存挺久，不登出下一個用電腦的人就能直接進你的 workflow。

其他側欄的每一項（Executions、Credentials、Templates、Insights、Admin panel……）是什麼、什麼時候用，在下一章會全部拆解。這章只要求你「登得進去、認得出主頁、找得到登出」。

常見卡關

登入這一關看起來簡單，但公司環境變數多，卡關的組合也多。下面是最常見的四種，照著試一遍通常能解掉：

  1. 登入頁一直轉圈、或整片白

    先排除是不是你這邊的問題：
    （1）按 Ctrl+Shift+R（Mac 是 Cmd+Shift+R）強制重新載入。
    （2）換一個瀏覽器試試看（Chrome 不行就試 Edge）。
    （3）換一台裝置（手機開 4G，不走公司 wifi）試試看。
    三個都不行，才回報給 IT 說「n8n.woowtech.io 全平台都連不上」——這時候通常是伺服器或 Cloudflare 那邊出事。

  2. 登入完看到「You do not have access」的紅色訊息

    你的帳號通了，但沒被加到任何 workspace／專案。不要一直重試登入，重試也是一樣。截圖那個訊息，貼給 IT 或 workspace 管理員，說「請把我加到 XX 這個 workspace」。權限一開，重新整理頁面就進得去。

  3. 忘記密碼

    登入頁 Sign in 按鈕下方有 Forgot my password 連結。點下去輸入 email，n8n 會顯示「已寄出重設信」的訊息。
    但這封信在 Woow 這一版寄不出去——實測 https://n8n.woowtech.io/rest/settings 回 smtpSetup: false，代表這個實例根本沒接 SMTP。畫面雖然顯示「已寄出」但你不會收到任何東西。唯一的解法是找 Owner／IT 用 CLI（n8n user-management:reset 之類）幫你手動重設。訊息模板：「請幫我重設 n8n.woowtech.io 的密碼，我的帳號是 xxx@woowtech.io，實例沒開 SMTP，麻煩用 CLI 或直接在後台改。」

  4. 手機看畫面破版、按鈕點不到

    先試 Chrome 的「桌面版網站」模式。還是不行的話直接放棄，換電腦操作。n8n 的 canvas 本來就不是給小螢幕用的，這是設計上的限制，不是 bug。手機上就當是「查看工具」，不要期待能編輯。

  5. 兩個帳號同時登入，登著登著就把彼此踢掉

    同一個瀏覽器只能保持一個 session。要同時用兩個帳號，開一個無痕視窗（Chrome：Ctrl+Shift+N），或裝第二個瀏覽器分開用。不要在同一個一般視窗開兩個分頁登兩個帳號，會互相蓋掉。

常見問題

一定要用公司的 n8n.woowtech.io 嗎？我可以自己註冊 n8n.io 的帳號用嗎？

公事一律用公司的。理由三個：

  • 公司 credentials（Google／Slack／內部 API 的 token）只存在公司實例，你在 n8n.io 官方註冊的帳號拿不到。
  • 你做的 workflow 同事要能接手、要能查執行記錄，只有公司實例做得到。
  • 公司資料進到外部雲端服務是資安地雷。

個人玩、學習用途，你想自架 n8n 或用 n8n.io 的免費雲端方案完全 OK，但那些跟公司 workflow 是分開的世界。

密碼多久要換一次？

Woow n8n 本身沒強制固定週期。但因為你的 credentials（等於幫公司代辦所有 SaaS 操作的鑰匙）都存在裡面，建議每三到六個月自己主動去 左下頭像 → Settings → Personal → Change password 換一次。發現有人可能拿到過你的密碼（比如共用電腦忘記登出），當下立刻換。

兩個帳號可以同時登入嗎？

同一個瀏覽器一次只能一個帳號 session。想同時用兩個帳號：一個開無痕視窗（Incognito）、或用不同瀏覽器（一個 Chrome 一個 Firefox）分開登。同一個瀏覽器一般視窗開兩個分頁登兩個帳號，會互相把對方登出，得不償失。

有 SSO 嗎？可以直接用 Google 帳號登入嗎？

n8n 官方支援 SAML、LDAP、OIDC 三種 SSO 登入方式，但全都是 Enterprise（付費企業版）功能。Woow 這一份是 Community（免費社群版），實測 /rest/settings 的 enterprise.saml / ldap / oidc 全都是 false，SSO 功能沒授權也開不了。所以：只能用 email + 密碼登入，沒有「Sign in with SSO」也沒有 Google 一鍵登入按鈕。如果將來 IT 升級到 Enterprise，登入頁才會多一顆 SSO 按鈕。

我的手機能收 n8n 的通知嗎？

n8n 本身不推 push 通知到手機。你會看到「通知」通常是你自己做的 workflow把訊息推到 Slack／Line／Email，然後那些 app 通知你。這章講的是登入介面本身，通知的做法之後在第 11 章「熱門 SaaS 整合」會教。

Personal settings 裡面有很多東西，我可以亂改嗎？

頭像展開的 Settings 分兩層：Personal（改自己的密碼、API keys、個人偏好）跟 Instance（Users、External Secrets、Log Streaming……會影響全實例）。前者可以放心試，後者只有 Owner 才看得到、也才點得動——Member 角色連進去都不會出現那些選項，所以你其實想亂點也點不到。詳細差別在附錄 A · 設定速查整理成表。

我在家能連 n8n.woowtech.io 嗎？要開 VPN 嗎？

不用。n8n.woowtech.io 走 Cloudflare Proxy 對外開放，家裡、咖啡店、客戶那邊都連得到。但因為對外開放，密碼強度更重要，不要用「Woow1234」這種好猜的。

登入成功了，下一步要做什麼？

建議路線：先看第 3 章「工作區導覽」把每個側欄項目跟中間畫面搞清楚，然後跳到第 13 章「Credentials 管理」把你會用到的第一組帳號（例如 Slack、Google）先設好，這樣後面章節做第一個 workflow 才有素材。急著動手也可以直接跳到第 8 章。
