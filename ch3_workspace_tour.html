第 3 章

工作區長什麼樣

很多人第一次登進 n8n 都會愣三秒——側欄一排陌生名字、中間一片空白畫布、右下角一堆小圖示。這章帶你把每個區塊點過一次，之後任何一章跟你說「打開 Executions」「開一個 Workflow 進去看設定」你都找得到。

為什麼要先認地圖

n8n 跟 Zapier / Make 最大的差別是「什麼都給你看」——所有 workflow、所有跑過的紀錄、所有金鑰都在同一個介面裡。這是好事，但代價就是剛開始畫面資訊量比較大。

已經在第 2 章成功登入 n8n.woowtech.io 的話，你眼前應該就是這個工作區。這章不動任何東西，只帶你認：

  • 左邊主側欄那七個項目分別是幹嘛的。
  • 打開一個 workflow 之後，畫面各個角落都是什麼。
  • Executions 頁為什麼是 debug 的救命恩人。
  • Templates、Credentials 這種之後會反覆用到的入口在哪。
本章不用動手：純粹「跟著我把滑鼠移到每個區塊上讀一次」的導覽章。真正動手做 workflow 要到第 8 章才開始，這章先讓你不會迷路。

主側欄從上到下七個項目

登入後畫面最左邊那條深色欄位就是主側欄（Main sidebar）。從上到下按順序長這樣：

項目幹嘛用的什麼時候會來
Overview首頁儀表板，最近開過的 workflow、最近跑過的紀錄、統計摘要。登入後第一眼、想快速回到「昨天弄到一半那個」。
Workflows你能存取的所有 workflow 清單，可以搜尋、過濾、開新分頁、標星號。幾乎每次進來都會用到，是主要工作面。
Templates官方模板 gallery，幾千個現成 workflow 一鍵複製到你的 workspace。想抄別人做好的（第 4 章詳講）。
Credentials金鑰、OAuth 授權、API token 的集中儲存。要串新的 SaaS 服務時、要跟同事分享共用帳號時（第 13 章詳講）。
Executions整個 workspace 跑過的每一次 workflow 紀錄。Debug 的黃金頁——workflow 半夜壞了、想看昨天到底跑了幾筆。
Insights企業版才有的用量統計、成功率報表。Woow 目前用不到，看到灰灰的就對了。
側欄最下方：What's new（鈴鐺）／Help（問號，連文件與社群）／頭像（點開才進 Settings 與登出）版本公告、外部說明文件連結、個人與 workspace 設定入口都在這裡。Settings 不是獨立側欄項目，要從頭像進去。調語言、換主題、看新版功能、登出。
提示：把滑鼠移到任何一個側欄圖示上會跳出中文（或英文）名稱。如果側欄是「收起」狀態（只看得到圖示沒有文字），點側欄底部那個 « / » 箭頭可以展開。
注意：你看到的側欄項目數量會跟你的權限有關。如果你是 workspace 的一般成員，可能看不到某些系統管理項目（例如 Insights、部分 Settings 分頁），這是正常的，不是壞掉。

打開一個 workflow 會看到什麼

從側欄點 Workflows → 隨便挑一個 workflow 點進去（沒有就先點右上角 + Create Workflow 開一個空的），你會進入 workflow 編輯畫面。這時候畫面分成好幾塊：

位置元件作用
最頂端左邊Workflow 名字（點一下可以改名）會出現在瀏覽器分頁跟 Workflows 清單。
最頂端中間三個分頁：Editor / Executions / Evaluations切換視角——編輯、看跑過的紀錄、看評測（進階）。
最頂端右邊Save + Execute Workflow + Publish / Unpublish存草稿、手動跑一次測試、把當前草稿發佈上線（讓排程／Webhook／事件觸發器真的開始接收事件）。
畫面中央Canvas（畫布）所有節點跟連線放在這裡，可以縮放拖動。
右下角一排小工具：Zoom in／Zoom out／Fit view／Tidy up／Mini-map畫布縮放與整理。
Canvas 右邊或空白處+ Add first step（新 workflow）或 + 按鈕（節點之間）叫出節點抽屜（Node panel）加新節點。
觀念：n8n 2.0 之後把過去的「Active 開關」換成Publish / Unpublish（發佈 / 取消發佈）模型：你在編輯的一直是草稿（draft），按 Publish 才會把當前這個版本推上線，排程 / Webhook / 訊息事件開始接收；沒 Publish 之前只有「Execute Workflow」手動按鈕能跑。這個改動就是為了避免手滑把改一半的 workflow 直接開啟。Woow 這台已經是 n8n 2.x，所以你在畫面右上角看到的會是 Publish 而不是 Active 開關。細節在第 10 章。

Canvas 上的節點長什麼樣

每一個節點都是一張矩形卡片放在畫布上，元素固定就這幾樣：

  • 左邊小圓點（input）：資料從這邊流進來。Trigger 節點沒有 input，因為它是流程的頭。
  • 節點 icon：Slack 的 #、Gmail 的信封等，一眼認出是哪個服務。
  • 節點名字：預設是節點類型名（例：Schedule Trigger），可以雙擊改成你看得懂的名字（例：每天早上八點）。
  • 右邊小圓點（output）：資料從這邊流出去。有些節點有多個 output（例：IF 節點有 true / false 兩個）。

連線是節點之間那條曲線：從上一個節點的 output 圓點拉到下一個節點的 input 圓點。滑鼠移到連線上會出現 × 可以刪除。

點一下節點會從右側滑出設定面板，裡面通常有三個分頁：

分頁內容
Parameters這個節點的所有欄位設定（要打哪隻 API、要傳什麼訊息、要抓哪個欄位）。
Settings節點層設定：錯誤時要不要繼續、重試次數、備註、node ID。
Output（跑過之後才有）這個節點上一次跑產生的資料，可以切 Table / JSON / Schema / Binary 看。
提示：Canvas 上按住 Space 拖動可以平移畫面，滾輪可以縮放。如果不小心把節點拖到看不見的地方，右下角 Fit view 一秒拉回來。

節點抽屜（Node panel）詳解

Canvas 空白處點右鍵或按 Tab、或直接點節點之間的 +、或空 workflow 中央那顆 + Add first step——都會叫出節點抽屜從右邊滑出來。這是加節點的唯一入口。

抽屜上方有搜尋框，直接輸入服務名（例：slack、gmail、sheet）最快。下方會按兩大類展開：

類別意義例子
Triggers（觸發器）Workflow 的開頭——決定什麼時候要跑。一個 workflow 通常只有一個 Trigger。Schedule Trigger（時間到）、Webhook（外部打過來）、Gmail Trigger（新信）。
Actions（動作）Workflow 的身體——真正做事的節點，看是要傳 Slack、寫 Sheet、還是打 API。Slack、Google Sheets、HTTP Request、OpenAI。

下方會再依用途分子分類（Communication、Data & Storage、Marketing、Development、AI 等）。找不到就直接搜尋，n8n 內建幾百個節點大部分都靠搜尋而不是分類找。三種節點的差別會在第 7 章完整拆解。

注意：如果你在空的 workflow 按 +，抽屜只會顯示 Triggers 給你選（因為第一個節點一定要是 Trigger 或 Manual Trigger）。有第一個節點之後，再按 + 才會出現 Actions。這不是 bug，是 n8n 硬性規定 workflow 必須有明確的開頭。

Executions 頁是幹嘛的

「Executions」在兩個地方都找得到：

  • 主側欄的 Executions：看整個 workspace 所有 workflow 的所有執行紀錄，可以依 workflow 篩選。
  • workflow 內頂端的 Executions 分頁：只看這個 workflow 自己的紀錄。

每一筆紀錄是「這個 workflow 跑過一次」的完整快照，包含：

欄位會告訴你
狀態Success（綠）／Error（紅）／Running（藍轉圈）／Waiting（等 Wait 節點）。
開始時間什麼時候被觸發的。
執行時間總共跑了幾秒。太久要開始擔心 timeout。
觸發模式是排程自動跑的、還是有人手動按 Execute、還是 Webhook 被打進來。
每個節點的資料點進紀錄可以逐節點看：吃了什麼 input、吐了什麼 output、錯在哪個節點的哪一行。
Debug 神招：workflow 半夜炸掉，最先來這裡。紅色紀錄點進去，n8n 會直接把炸掉的節點紅框標出來，右邊面板 Output 分頁就是完整錯誤訊息。第 17 章錯誤處理會回來這裡教你系統化除錯。
觀念：Executions 預設只保留一段時間（Woow 這台的設定值可以到 Settings 看），舊的會被清掉。真的要長期存證的資料自己另外寫進 Sheet 或資料庫，不要靠 Executions 當歷史紀錄。

Templates 入口在哪

Templates 兩個入口都通：

  • 主側欄的 Templates：直接進 gallery。
  • Workflows 頁右上角的「Templates」按鈕（有些版本叫 Browse templates）。

進去之後可以做這幾件事，不用馬上動：

  1. 搜尋或分類找模板

    搜尋框輸關鍵字（例：slack digest、ai chat），或用左邊分類（AI、Marketing、Sales、DevOps 等）過濾。

  2. 預覽 workflow 長怎樣

    點進一個模板會看到縮圖、用了哪些節點、作者、下載次數、簡短說明——像 App Store 的 app 頁面。

  3. 一鍵 Use workflow

    按 Use workflow 按鈕，n8n 會複製這個模板到你的 workspace，變成一個新 workflow 直接讓你進去編輯。原始模板不會被動到。

怎麼挑好模板、怎麼看模板需要哪些 credential、模板貼過來要改哪些欄位，第 4 章會手把手示範一次。

Credentials 頁在哪

側欄 Credentials 點進去，會列出這個 workspace 裡所有你有權存取的 credential：Slack Bot Token、Google OAuth、Gmail、OpenAI API Key、HTTP Header Auth 等等。

每一筆 credential 顯示：

  • Credential 名字（自己取的，例：Slack - #general 通知）。
  • 類型（Slack API、Google Sheets OAuth2 等）。
  • 擁有者 / 分享對象。
  • 建立與最後編輯時間。
危險：Credential 一但存進 n8n，任何在同一個 workflow 裡選到它的節點都能拿去用。跟同事分享 credential 之前先想清楚——他可以用你的 Slack 帳號發任何訊息。細節、OAuth 流程、共用界線都在第 13 章。
觀念：Credential 跟 workflow 是分開存的。刪掉一個 workflow 不會刪 credential；反過來刪掉 credential，用到它的 workflow 會在該節點顯示紅色警告。這個設計是刻意的——同一組 credential 可以被很多 workflow 共用。

右下角三個好用小工具

Canvas 右下角那排小按鈕很多人一整年都沒點過，但其實超救命：

按鈕快捷鍵什麼時候用
Zoom in / Zoom out（＋／−）滾輪也行節點看不清楚、想看細節。
Fit view（田字圖示）—整個 workflow 一次縮到剛好塞滿畫面。找不到節點時的第一招。
Tidy up（掃把 / 對齊圖示）—自動把亂七八糟的節點排整齊——比人工拖快 10 倍。
Mini-map（縮圖）—展開右下角的小地圖，大 workflow（20+ 節點）想快速跳到另一區。
提示：n8n 目前沒有全域的「? 快捷鍵 cheat sheet」浮窗，官方文件本身就把快捷鍵一頁列出來（搜尋 n8n keyboard shortcuts）。實務上先記住 Tab（在節點旁按會叫出節點抽屜）、Ctrl/Cmd+S（存草稿）、Ctrl/Cmd+A（框選全部節點）、拖曳時按住 Shift（貼齊格線）就夠用了。

常見卡關

  1. 打開 workflow 是一片空白

    正常——這是全新的空 workflow。中央會有一顆 + Add first step，點下去就會出現節點抽屜（只顯示 Triggers）。挑一個 Trigger 開始。

  2. 節點拖不動 / 改不了設定

    大概是你沒有 Editor 權限只有 Viewer。頁面右上角會看到「Read only」提示。找 workspace 管理者升權限，或請他把 workflow 分享給你。

  3. 節點連線連不起來

    要從 output 圓點（節點右邊）拉到 input 圓點（下一個節點左邊）。中間拉的過程中不要放開；接近目標圓點時會亮綠色就可以放。反向（input 拉到 output）拉不起來是刻意的。

  4. 找不到剛才跑的執行紀錄

    兩個地方都能看：workflow 內頂端 Executions 分頁（只看這個 workflow）、或側欄 Executions（看全部）。如果剛才是按 Execute Workflow 手動跑，紀錄會標成「Manual」；如果是 Trigger 觸發的會標「Trigger」。

  5. Canvas 縮到看不見自己在哪

    右下角 Fit view（田字圖示）按下去，整個 workflow 會自動縮回剛好塞滿畫面。這是找不到節點時的第一招，比任何快捷鍵都直覺。

常見問題

介面可以切成全中文嗎？
可以。點側欄底部你的頭像 → Settings → Personal → Language，下拉選單有繁體中文可以選（不同 n8n 版本翻譯完整度不太一樣，有些節點內文欄位還是英文，這是正常的）。
有沒有深色模式？
有。同樣在 Settings → Personal 找 Theme，可以選 System（跟系統走）／Light／Dark。切完不用重整，即時套用。
有沒有快捷鍵一覽？
n8n 目前沒有在 App 內建的 ? 快捷鍵浮窗（很多舊教學會這樣寫，但實測按 ? 不會跳）。官方把快捷鍵列在文件的 Keyboard shortcuts 頁面，Google 搜「n8n keyboard shortcuts」就找得到。實務上背 Tab（節點旁叫抽屜）、Ctrl/Cmd+S（存草稿）、Ctrl/Cmd+Enter（Execute Workflow）、拖曳按 Shift（貼齊）就夠。
Canvas 上節點亂成一團怎麼辦？
兩招：右下角 Tidy up 讓 n8n 自動對齊排整齊；或框選一批節點（滑鼠框選）拖到你想要的位置。真的很大就開 mini-map 看整體再局部整理。
可以同時打開兩個 workflow 嗎？
可以，在瀏覽器另開分頁就好——每個 workflow 都是獨立的 URL。從 Workflows 清單按住 Ctrl（Mac 是 Cmd）點 workflow 名字會直接開新分頁。
不小心關掉右邊那個節點設定面板了怎麼辦？
再點一次那個節點就會叫回來。或雙擊節點也可以。面板永遠不會真的「消失」，只是折疊而已。
