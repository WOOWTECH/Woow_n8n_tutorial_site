為什麼公司需要 n8n

翻開公司裡任何一個部門，都有一堆「有人在做，但其實不該有人做」的重複工作：把訂單資料從 A 系統手工複製到 B 表格、Line 客戶問題手動轉派、每天早上 8:00 打開 Excel 抓昨天業績再貼進報表——這些每天吃掉 1-2 小時，一年就是 300 個工時。

這一類工作的共通點是：規則明確、資料在系統裡、動作重複。這正是 n8n 的甜蜜點——把「規則」畫成 workflow，n8n 24 小時幫你跑，你只要偶爾看報表確認沒壞。

觀念：Zapier／Make 大家聽過，n8n 是它們的開源版：一樣拖拉節點畫流程，但可以自架、資料留在自己家、按量計費不用綁月費、想接什麼就接什麼。GitHub 上超過 130k ★，是這類工具裡社群最活的一個。

n8n 是什麼

n8n（讀作「n-eight-n」）是一款開源工作流自動化引擎。畫面上是一片畫布，你把「觸發器」（Trigger）跟「動作節點」（Action）拉出來連起來，就是一條 workflow：

  • 觸發可以是排程（每天早上 8:00）、Webhook（有人填表單）、系統事件（Gmail 收到新信）。
  • 動作是接下來要做的事：查 Google Sheets、發 Slack、開 Notion 頁、丟 HTTP request 到內部系統。
  • 資料從第一個節點流到最後一個，中間可以判斷、分岔、合流、轉換格式。

官方 + 社群加起來超過 2,500 個節點（Slack、Gmail、Notion、Airtable、Google Workspace、Salesforce、Stripe、Line、Telegram、Discord、AI Agent……）——沒有現成節點的服務，用 HTTP Request 節點手打 API 也能接。

提示：你不需要理解上面這段。這本手冊接下來的兩種模式，就是把「n8n 是什麼」全部藏起來——你只要開口說「我想自動化這件事」，剩下的 WoowTech 接手。

兩種模式，看你要不要自己有一顆

不管走哪一條，你都不會碰到 n8n 的畫布——WoowTech 代寫、代維、代排錯。差別只在：n8n 這台伺服器要放在你家，還是放我們家。

模式 A · HAOS add-on 版

給：已經有 Home Assistant OS 或想把資料留在自家的中小企業／個人／診所／店家

n8n 以 Home Assistant Add-on 形式裝在你自家的 HAOS 主機上，資料完全不出家門。WoowTech 代寫 workflow、遠端維護、templates 打包送。

  • n8n 跑在你自家的機器，資料 100% 本地
  • WoowTech 代寫 workflow，含測試與上線
  • Template Package：從我們既有 workflow 庫挑合適的直接搬過來
  • 季度巡檢 + 出問題 8 小時內回覆
  • 與同一台 HA 上的 pi agent、smart home 打通
最好上手

模式 B · 雲端 PaaS 版

給：想立刻上線、不想自架、可接受 workflow 跑在 WoowTech 雲端的公司

直接在 n8n.woowtech.io 開一個帳號，共用 WoowTech 維護的 n8n 雲端環境。多用戶、免自架、含 SaaS credentials pool（部分服務可共用授權）。

  • 當天開帳號、當天用，免自架、免維護
  • 版本、備份、SSL、監控全部 WoowTech 顧
  • 共享 credentials pool（省 SaaS 授權費）
  • 使用量計費，off-peak 幾乎不算錢
  • 複雜／機敏 workflow 可搬回 add-on 模式
提示：不確定選哪個？大部分公司從模式 B（雲端）試水一個月，兩三支 workflow 見到成效之後，敏感度較高的（客戶名單、財務）再搬到模式 A（本地 add-on）。

模式 A · HAOS add-on 版細節

如果你家／公司已經有一台 Home Assistant OS 主機（甚至是 pi agent 教學裡那台），n8n 只是多裝一顆 Add-on。整個安裝、設定、workflow 部署都由 WoowTech 遠端做，你只要把 HA 的存取權限開一個給我們就好。

你會拿到什麼

  • n8n add-on 裝機服務：從 add-on repository 加入、安裝、初始化、SSL / reverse proxy 設定，一次到位。
  • N 支代寫 workflow：專案簽約時你列 5-10 個想自動化的場景，WoowTech 逐一畫成 workflow、跟你的實際帳號測試、上線。
  • Template Package：從 WoowTech 既有 workflow 庫（訂單通知、客戶追蹤、每日報表、Line Bot 客服……）挑合適的直接搬過來，加你的欄位就能用。
  • 季度巡檢：每季一次遠端進去看 execution 錯誤率、更新版本、清理過期資料。
  • 問題支援：workflow 半夜掛了，WoowTech 值班工程師 8 小時內回覆（工作日）；緊急案例（付款、營運）另定 SLA。

什麼公司適合這條路

  • 客戶名單、財務、病歷、內部 SOP——資料敏感度高、法規要求本地儲存的公司
  • 已經在用 Home Assistant 管辦公室、機房、案場的公司
  • 希望 n8n 跟同一台 HA 上的 pi agent 或 smart home 深度整合的用戶
  • 網路品質不穩、需要斷網也能跑內部 workflow 的場所
硬體門檻：n8n add-on 對硬體不苛：RPi 5 (8GB)、NUC、或任何跑得動 HAOS 的 x86 機器都行。單機建議上限 30-50 支活躍 workflow，超過建議升級或改走模式 B。

模式 B · 雲端 PaaS 版細節

不想碰硬體、不想想 IT 的公司走這條。WoowTech 在雲端跑一組 n8n 實例（n8n.woowtech.io，目前 v2.32.7 Community 版），你來開一個 workspace，跟其他客戶邏輯隔離、資料獨立。裝機成本零、開通當天可用。

你會拿到什麼

  • 專屬 workspace：多用戶、獨立資料庫、獨立 execution 歷史；跟其他客戶完全隔離。
  • 共享 credentials pool（選配）：SendGrid、Twilio、OpenAI、Slack 官方 App 等常用服務可以掛在 WoowTech 池底下，你不用申請帳號、按用量分攤——第一次自動化最省事的做法。
  • 代寫 workflow 服務：跟模式 A 一樣，WoowTech 代寫、代測、代上線。
  • 使用量計費：一支 workflow 一天跑 24 次跟跑 24,000 次差很多，我們按實際 execution 數計價，off-peak 用戶幾乎不算錢。
  • SLA 99.5%：全站監控＋自動備份，重大事件 4 小時內回覆。

什麼公司適合這條路

  • 從來沒碰過 n8n、想找一支 workflow 試水的公司
  • 資料本身就在雲端 SaaS（Google Workspace、Notion、Airtable、Slack）——搬到 WoowTech 雲跟原本沒差
  • 不想維護硬體、不想想版本升級的公司
  • 先用雲端半年，之後有敏感度需求再局部搬到模式 A 的公司
提示：雲端版跟本地版是同一套 n8n，workflow 可以互相匯出匯入。今天在雲端做的 workflow，明天想搬到自己家的 add-on，直接匯出 JSON 過去就是同一支。

Email 自動歸檔＋回覆

AI Agent 資料整理

把 100 份客戶回饋 PDF 丟到雲端資料夾，n8n 一份一份讀，用 AI Agent 節點抽出重點、標籤、情緒，寫到 Airtable 供分析。

資安、備份、SLA

資料儲存位置

  • 模式 A（HAOS add-on）：所有 workflow 定義、execution 歷史、credentials 都在你自家的 HAOS 主機。WoowTech 只透過遠端連線協助維護，事後即斷線，不留 copy。
  • 模式 B（雲端 PaaS）：資料存於 WoowTech 台灣機房的 VM，每日自動異地備份。跨客戶邏輯隔離、每個 workspace 獨立資料庫。

Credentials（金鑰）保管

  • 兩種模式都採 n8n 原生的加密儲存機制（AES-256），只有 workflow runtime 能解密。
  • WoowTech 工程師遠端維護時，不能匯出、不能複製到別處——n8n 本身沒有這個功能，我們也不繞開。

常見問題

費用怎麼算？
兩種模式都是「一次性建置費 + 月費（含代維護與 N 支 workflow 免費更改）」。實際費率會依 workflow 數量、預期 execution 量、SLA 等級調整——請洽 WoowTech 業務或您的經銷商索取報價單。
我可以自己改 workflow 嗎？
可以。兩種模式都會給你完整的 n8n 存取權，你想學著改、想自己拉新 workflow 都行——WoowTech 這邊的角色是「當你不想／不會的時候都在」。想學怎麼改，直接看本站的 n8n 入住指南 22 章教學。
模式 B 的 credentials pool 是什麼？跟我自己申請 Slack／OpenAI 差在哪？
你自己申請每一個 SaaS 帳號＝每一支月費你付、額度你頂。credentials pool 是 WoowTech 幫多客戶集中申請商業帳號、按實際用量分攤——小量用戶明顯便宜，帳單也單純（一張）。要獨立帳號的客戶也可以指定不進 pool。
可以先跑模式 B，之後搬到模式 A 嗎？
可以。這是常見路徑——先用雲端試水一個月、驗證 workflow 對 KPI 有效，之後敏感的 workflow 匯出 JSON 搬到自家 HAOS add-on。WoowTech 協助資料搬遷、憑證重掛。
Woow 的 n8n 是社群版還是企業版？功能會不會少？
目前是 Community Edition（v2.32.7 之後跟隨社群升版），功能對中小企業一般用途完全夠——AI Agent、自訂節點、Sub-workflow、Error Workflow 全部有。企業版獨有的（LDAP／SAML SSO、Advanced RBAC、Version Control 整合）如有需求可另談混合部署。
公司完全沒有 IT 部門，也能導入嗎？
最適合。這正是這套方案的初衷——WoowTech 從溝通需求、寫 workflow、上線、維護全包。你只需要有一位「聯絡窗口」跟我們對接就好。
Zapier 用得很習慣，值得換 n8n 嗎？
看兩件事：（1）Zapier 月費有沒有超過 100 美金？（2）有沒有需求它做不到（例如接自己內部系統、要迴圈跑幾百次）？中一項就值得聊。Zapier 現有的 Zap，n8n 幾乎都能重畫，通常還更彈性。
